# 리스크 및 법적 유의사항

이 문서는 법률 자문이 아닙니다. 실제 운용 전에 증권사 약관과 관련 법령을 직접 확인하시고,
필요하면 전문가의 조언을 받으세요.

---

## 1. 투자 위험

- **이 앱은 수익을 보장하지 않으며, 투자 자문을 제공하지 않습니다.**
- 자동매매는 손실을 자동화할 수도 있습니다. 사람이 망설일 상황에서 기계는 망설이지 않습니다.
- 과거 데이터로 좋은 성과를 낸 전략이 미래에도 통한다는 보장은 없습니다
  (과최적화, overfitting).
- **잃어도 생활에 지장이 없는 금액만** 투입하세요.

---

## 2. 기술적 위험 — 앱이 멈추는 경우

아래 상황에서는 **손절 주문조차 나가지 않습니다.**

| 상황 | 결과 |
|---|---|
| 기기 배터리 방전 / 전원 꺼짐 | 매매 중단 |
| 제조사 배터리 최적화로 서비스 강제 종료 | 매매 중단 (알림도 사라짐) |
| 네트워크 끊김 (지하철, 엘리베이터, 해외 로밍) | 주문 전송 실패 |
| 증권사 API 장애 또는 정기 점검 | 조회·주문 모두 실패 |
| API 호출 한도 초과로 일시 차단 | 조회·주문 모두 실패 |
| 앱 크래시 | 매매 중단 |

**대응:**
1. 배터리 최적화를 해제하세요 (`user-guide.md` §6-3).
2. **증권사 앱에서 별도의 스탑로스 주문을 병행하세요.** 앱이 죽어도 거래소에 남아 있는
   유일한 안전망입니다.
3. 장 마감 후 매매일지를 확인해 의도대로 돌았는지 점검하세요.

---

## 3. 주문 관련 위험

- **시장가 주문은 예상과 다른 가격에 체결될 수 있습니다.** 특히 거래량이 적은 종목,
  상·하한가 근처, 장 시작 직후에 그렇습니다.
- **미체결 주문 관리 기능이 없습니다.** 지정가 주문을 쓰면 미체결 상태로 남을 수 있으며,
  이 앱은 미체결 정정·취소를 자동으로 하지 않습니다.
- **잔고 반영 지연.** 주문 직후 잔고 조회에 즉시 반영되지 않을 수 있어,
  다음 사이클에서 중복 매수가 시도될 수 있습니다. 재주문 쿨다운이 이를 완화하지만
  완전히 막지는 못합니다.
- **증거금·미수 관련 규칙을 계산하지 않습니다.** 현금 주문만 다루며,
  D+2 결제 주기로 인한 예수금 차이는 고려하지 않습니다.

## 4. 법적·규제 사항

### 4-1. 본인 계좌 운용

본인 명의 계좌에서 본인이 만든 프로그램으로 매매하는 것 자체는 일반적으로 허용됩니다.
다만 **증권사의 Open API 이용약관**에 동의한 범위 안에서만 가능합니다.

### 4-2. 타인 자금 운용은 인가가 필요합니다

- 타인의 자금을 대신 운용하거나, 타인의 계좌를 이 앱으로 매매하는 것은
  **자본시장법상 투자일임업**에 해당할 수 있으며, 금융위원회 인가 없이는 불법입니다.
- 이 앱을 배포하면서 **매매 신호를 제공하고 대가를 받는 것**은
  유사투자자문업 신고 또는 투자자문업 인가 대상이 될 수 있습니다.
- 수익률을 광고하거나 보장하는 행위는 별도의 규제를 받습니다.

**개인이 본인 계좌에 쓰는 용도를 벗어난다면, 반드시 법률 검토를 받으세요.**

### 4-3. 시장질서 교란 행위 금지

자동매매라도 다음 행위는 금지됩니다.

- 시세조종 (허수주문, 통정매매, 가장매매 등)
- 대량의 주문·취소를 반복해 시장에 부담을 주는 행위
- 미공개 중요정보 이용

이 앱은 단순 기술적 지표 기반 매매만 수행하므로 통상적인 사용에서는 해당하지 않지만,
전략을 직접 수정할 때는 위 사항을 염두에 두세요.

### 4-4. API 이용약관

- 호출 한도를 초과하면 이용이 제한될 수 있습니다.
- API 키를 타인과 공유하거나 재판매하는 것은 약관 위반입니다.
- 증권사가 API 사양을 변경하거나 서비스를 중단할 수 있으며,
  그로 인한 손실에 대해 증권사는 책임지지 않는 것이 일반적입니다.

### 4-5. 앱 배포 시

이 앱을 Google Play 등에 배포하려는 경우, 금융 서비스 관련 정책을 별도로 확인해야 합니다.
스토어 정책은 수시로 바뀌므로 **배포 시점의 최신 정책을 직접 확인**하세요.

## 5. 개인정보 및 보안

- API 키와 접근토큰은 **기기 안에만** 암호화 저장되며, 개발자를 포함한 외부로 전송되지 않습니다.
- 매매일지도 기기 내 로컬 DB에만 저장됩니다.
- **루팅된 기기에서는 사용하지 마세요.** 암호화 저장소의 보호 수준이 크게 낮아집니다.
- 기기를 분실했거나 양도할 때는 `설정` 탭에서 **저장된 키를 삭제**하고,
  증권사 개발자센터에서 **해당 APP KEY를 폐기**하세요.
- 릴리스 빌드에서는 HTTP 본문 로깅이 꺼집니다. 디버깅을 위해 켰다면 **반드시 다시 끄세요.**
  로그에 토큰과 계좌번호가 그대로 남습니다.
