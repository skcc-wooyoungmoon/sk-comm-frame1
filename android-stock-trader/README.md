# AutoTrader — 안드로이드 주식 자동매매 앱

한국투자증권 Open API를 이용해 국내 주식을 자동으로 매매하는 안드로이드 앱입니다.
Kotlin + Jetpack Compose로 작성되었고, 매매 로직은 안드로이드에 의존하지 않는
별도 모듈로 분리되어 있어 JVM에서 단위 테스트가 가능합니다.

> ⚠️ **투자 자문이나 수익 보장을 제공하지 않습니다.** 모든 손실은 사용자 본인의 책임입니다.
> 기본값은 실제 주문을 내지 않는 **기록 전용 모드**이며, 실전 사용 전에
> [리스크 및 법적 유의사항](docs/risk-and-compliance.md)을 반드시 읽어주세요.

---

## 무엇을 하는 앱인가

1. 등록한 종목의 시세를 주기적으로 가져와
2. 선택한 기술적 전략(이동평균 교차 / RSI / 볼린저 / MACD)으로 매수·매도 신호를 판단하고
3. **리스크 한도를 통과한 경우에만** 주문을 냅니다.
4. 판단한 내용과 **주문하지 않은 이유**까지 전부 매매일지에 남깁니다.

## 핵심 안전장치

| 장치 | 동작 |
|---|---|
| 기록 전용 모드 | **기본 켜짐.** 신호만 기록하고 실제 주문은 내지 않음 |
| 손절 / 익절 / 트레일링 스탑 | **전략 신호보다 우선** 평가 — 전략이 매수를 외쳐도 손절이 먼저 나감 |
| 일일 손실 한도 (킬 스위치) | 당일 손실이 한도에 닿으면 신규 매수 전면 중단 (청산은 계속 허용) |
| 종목당 비중 / 보유 종목 수 한도 | 한 종목에 몰빵하거나 문어발로 벌리는 것을 차단 |
| 일일 주문 건수 한도 | 오작동으로 주문이 폭주하는 것을 차단 |
| 재주문 쿨다운 | 신호 떨림에 의한 연속 주문 억제 |
| 장 시간 검사 | 주말·휴장일·장 시작 직후에는 주문하지 않음 |
| 실전 전환 확인 | 실전 모드 전환과 실주문 시작 시 각각 확인 대화상자 |

## 화면

| 탭 | 기능 |
|---|---|
| 대시보드 | 엔진 상태, 계좌 잔고, 보유 포지션, 대상 종목 관리, 시작/중지 |
| 전략 | 전략 선택과 파라미터, 리스크 한도 설정 |
| 백테스트 | 현재 설정을 과거 일봉에 적용해 수익률·MDD·승률·손익비 확인 |
| 매매일지 | 주문·보류·오류 기록 (사유 포함) |
| 설정 | 모의/실전 전환, API 키 관리 |

## 빠른 시작

```bash
# 매매 로직 테스트 (안드로이드 SDK 불필요)
./gradlew :core-trading:test

# 앱 빌드
./gradlew :app:assembleDebug
```

1. 한국투자증권 계좌 개설 → 개발자센터에서 Open API 신청 → APP KEY/SECRET 발급
2. 앱 실행 후 `설정` 탭에서 키와 계좌번호 입력 (모의투자 모드 유지)
3. `대시보드`에서 종목 등록, `전략` 탭에서 전략·한도 설정
4. `백테스트`로 전략 성향 확인
5. **기록 전용 모드로 최소 2주 검증** 후에만 실전 전환

자세한 절차는 **[사용 가이드](docs/user-guide.md)** 를 따라가세요.

## 기술 스택

Kotlin · Jetpack Compose · Coroutines · Room · Retrofit/OkHttp · kotlinx.serialization ·
EncryptedSharedPreferences · Foreground Service

- `minSdk 26` / `targetSdk 35`
- 매매 로직 단위 테스트 60건 (JVM)

## 확인이 필요한 부분

증권사 API의 **경로와 거래 코드(TR_ID)는 개편될 수 있습니다.**
해당 상수는 [`KisEndpoints.kt`](app/src/main/kotlin/com/sk/autotrader/data/remote/KisEndpoints.kt)
한 곳에 모아두었으니, 실계좌 연결 전에 개발자센터 최신 문서와 대조하세요.
수수료율·증권거래세율도 연도와 시장에 따라 달라지므로
[`CostModel`](core-trading/src/main/kotlin/com/sk/autotrader/core/backtest/Backtester.kt)의
기본값을 본인 계좌 기준으로 교체해야 백테스트가 의미를 가집니다.
